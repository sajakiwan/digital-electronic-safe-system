# # Digital Electronic Safe System

## Overview
A digital electronic safe system designed and built from scratch as an Electrical Engineering project. The system implements secure 3-digit code authentication using discrete digital logic components.

## Key Features
- 3-digit access code authentication
- 7-segment display for digit indication
- Error counting for incorrect code attempts
- LED indicators for system status
- Automatic reset after three incorrect attempts
- Buzzer alarm activation after repeated failed attempts
- External control inputs using * and #
- Timed indication after successful code entry

## Hardware Components
- D Flip-Flops
- Logic Gates
- Counters
- Timers
- Transistor
- 7-Segment Displays
- LEDs
- Buzzer

## Design & Implementation
The system was designed and assembled from individual electronic components and wired manually. The project involved digital logic design, hardware integration, troubleshooting, testing, and validation of the complete system.

Digital Logic Design • Hardware Design • Circuit Integration • Sequential Logic • D Flip-Flops • Counters • Timing Circuits • Troubleshooting • Testing & Verification
